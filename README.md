# Jeffrey Hoelzel Jr. Portfolio

This repository contains the source for my personal portfolio website. It highlights my work as an AI/ML, full-stack, and data engineer, including projects, experience, and resume.

## Tech stack

- SvelteKit 2 and Svelte 5
- TypeScript
- Vite
- `@sveltejs/adapter-static` for static-site output
- `svelte-icons`

## Requirements

- Node.js 20.19+ or 22.12+ (a current LTS release is recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite (normally `http://localhost:5173`).

Other useful commands:

```bash
npm run check    # Type-check and validate Svelte files
npm run build    # Create the static production build in dist/
npm run preview  # Preview the production build locally
```
